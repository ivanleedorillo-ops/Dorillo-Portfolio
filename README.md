# Dorillo Portfolio

Personal portfolio website for Ivan Lee Dorillo, featuring an introduction, skills, selected projects, and contact information.

## Project structure

```text
.
|-- index.html
|-- contact.php
|-- assets/
|   |-- css/
|   |   `-- style.css
|   `-- images/
|       |-- profile/
|       |   `-- ivan-dorillo-portrait.png
|       `-- projects/
|           |-- craigslist-redesign.png
|           |-- horizon-download.png
|           |-- secret-wall.png
|           |-- php-learning-journey.png
|           |-- research-vault.png
|           `-- corner-cravings.png
`-- .gitignore
```

## Run locally

Place the project in the XAMPP `htdocs` directory, start Apache, and open:

```text
http://localhost/Dorillo%20Portfolio/
```
